## 🌟 产品简介

《长安云阙 · AR 文旅助手》是一款以盛唐文物活化 IP——赤金走龙「云阙」为向导的城市文旅 AR 导览微信小程序。用户既可**不到现场云游**，逐点位在线复原殿宇、听懂典故、集齐龙鳞；也可**到现场 AR**，扫描解说牌与文物，在遗址上叠加盛唐影像；还能在**云阙商城**把「长安」带回家。

项目首发**大明宫国家遗址公园**，并已扩展**大雁塔·大慈恩寺**与**青龙寺·密法东传**，验证了平台化能力：**复制一份景点数据、替换内容，即可快速接入新城新景**。

## ✨ 核心功能

| 模块 | 说明 |
|---|---|
| 🏛 **景点数字馆** | 历史时间线、主要看点、到访信息，数据驱动、模板可复用 |
| 🐉 **云阙 AR 巡游** | 云游 / 现场双模式；逐点位互动小剧场，AR 复原殿宇、可溯源史料卡、集鳞仪式动画 |
| 🎞 **动态复原 + 配音** | 无真 3D 时以 Seedance 动态复原视频替代，每点位配云阙 / 旁白 TTS 配音 |
| 🏺 **文物图鉴** | 现场扫描收录文物，配档案、云阙讲解与史料出处 |
| 🐲 **龙鳞与集章** | 龙鳞按景点分组、云游现场皆可集；通关文牒「集章」仅现场获得 |
| 🛍 **云阙商城** | 6 大品类 54 款商品，支持 AR 预览、加购结算与预售意向登记 |
| 👤 **个人中心** | 更换头像 / 编辑昵称签名、龙鳞墙、三统计格、旅人成就称号 |

> 现场 AR 在机型不支持、拒绝授权或不在现场时，会**自动降级**为复原视频 / 图 + 云阙讲解，**绝不黑屏、链路不断**。

## 🚀 快速开始

1. 用「**微信开发者工具**」导入仓库根目录。
2. 使用真实 AppId `wxf9d2785d37c216d4`（勿用游客 `touristappid`，否则云开发面板无法打开）。
3. 安装依赖并「构建 npm」：
   ```bash
   npm install
   ```
4. （可选）开通云开发后，将环境 ID 填入 `miniprogram/config/index.ts` 的 `cloudEnvId`，并部署 `intention` 云函数，详见 `docs/cloud-switch.md`。
5. 首页点「**随我入宫**」即可体验丹凤门剧场；真机可体验现场 AR。

## 🧩 三条主链路

**① 云游集鳞（约 10–15 分钟，不到现场）**
首页「随我入宫」→ 逐句推进剧情、AR 复原、史料卡 → 接过龙鳞、前往下一点位 → 终章集齐龙鳞，生成可保存 / 分享的「长安祈愿卡」。

**② 现场 AR 复原**
切「现场」模式 → 真机 marker 识别 + VKSession 在遗址叠加殿宇 → 不支持时以 LBS / 罗盘方位触发，自动降级不黑屏。

**③ 商城意向闭环**
浏览商品、详情页 AR 预览 → 加购结算或预售登记 → 填称呼、手机号（前端 + 云函数双重校验）→ 云端 `intention` 真实提交 / 查询，未配云环境自动降级本地登记。

## 🏗 技术架构

- **框架**：微信小程序原生 + TypeScript（运行时编译插件）
- **AR**：VisionKit / VKSession（marker / 平面），LBS / 罗盘兜底，看门狗降级
- **后端**：微信云开发（云函数 `intention` + 云数据库），本地 Mock 可无缝切换
- **美术 / 媒体**：Seedream 5.0 Pro 生图、Seedance 2.5 生视频、TTS 配音；重媒体走 CDN 不入包
- **组件化**：内联 SVG + 纯 CSS 的 `dragon-scale` 龙鳞组件与 `line-icon` 图标集，任意分辨率清晰、零网络请求

```
changan-yunque-ar/
├── miniprogram/            小程序源码
```

## 🗺 多景点平台复制

平台将「内容」与「能力」彻底解耦。接入一个新景点只需：

1. 在 `data/spots/` 新增景点元数据，在 `data/scenes/<spot>/` 新增点位剧场，在 `data/relics/` 新增文物；
2. 在各 `index.ts` 聚合中登记（巡游、图鉴、分享卡、AR 均由 `spotId` 自动适配）；
3. 替换对应美术 / 视频 / 配音资源（重媒体走 CDN）。

**无需改动任何页面与交互逻辑**，即可让一座新城、新景点拥有完整的云游、AR、图鉴与商城能力。

## ⚖️ 合规声明

- 文物相关形象统一标注「**文物灵感 / AIGC 再现**」，不冒充原文物、不夸大祈福功效；
- 历史人物与典故以正史 / 考古资料为准，史实零硬伤，史料卡可溯源；
- 预售阶段暂不扣款；位置等敏感信息仅在用户主动授权后于前台使用，不后台采集、不对外共享。
