# 长安云阙 · AR文旅助手

跟着赤金走龙「云阙」，在盛唐宫阙与今日遗址之间，把长安走一遍、把典故听一遍、把「长安」带回家。

微信小程序：**景点数字馆 ＋ 云阙 AR 巡游 ＋ 云阙商城**。已并线落地两个景点——首发**大明宫国家遗址公园**（七点位剧场）与第二景点**大雁塔·大慈恩寺**（五点位剧场），验证「可扩展多景点城市文旅 AR 平台」模板：复制景点数据、替换内容即可快速接入新景点。

## 功能特性
- **景点介绍（数字馆）**：历史时间线、主要看点、到访信息，可复用模板。
- **云阙 AR 巡游（多景点）**：大明宫七点位互动小剧场——丹凤门、含元殿、宣政殿（廊下食）、紫宸殿、太液池、麟德殿、玄武门；大雁塔五点位——大慈恩寺山门、翻经院译场、雁塔圣教序碑、雁塔题名、塔名由来（终章）。巡游页可在景点间切换；云游/现场双模式，每景点各集一组龙鳞（大明宫七片、大雁塔五片），均配可溯源史料卡。每点位配 **Seedance 动态复原视频**（无真 3D 以视频替代）与 **云阙/旁白配音**，集鳞有仪式动画。
- **龙鳞与集章分离**：龙鳞按景点分组、云游/现场皆可集；通关文牒「集章」仅现场（真机 LBS/识别、模拟器 demo 打卡）获得，云游不盖章。
- **云阙商城**：典藏复刻、潮玩盲盒、城市限定、唐妆首饰、数字AR、体验预约；支持 AR 预览与预售意向登记。

## 技术栈
微信小程序原生 ＋ TypeScript；现场 AR 用 VisionKit/VKSession（marker/平面），**无真 3D 时以 Seedance 2.5 动态复原视频替代**；美术由 Seedream 5.0 Pro 生成、配音由 TTS 生产，微信云开发支撑意向登记。

## 快速开始
1. 用「微信开发者工具」导入仓库根目录。
2. 仓库已填真实 AppId `wxf9d2785d37c216d4`（不可用游客模式 `touristappid`，否则「云开发」面板打不开）。
3. 安装依赖并「构建 npm」（XRFrame）。
4. 开通云开发后，将环境 ID 填入 `miniprogram/config/index.ts`。
5. 首页点「随我入宫」体验丹凤门剧场；真机上可体验现场 AR。

- 横版概览：`media/changan-yunque-promo.mp4`（82 秒电影感概览，盛唐古风配乐）。
- **M3 动态亮点（84.7 秒 · 竖屏 9:16）**：`media/changan-yunque-m3-highlight.mp4`——赤金走龙开场、七点位 Seedance 动态复原（配云阙/旁白配音与描金点位角标）、四大高质感页面 Ken Burns、数字文物投影收尾，盛唐古风配乐。

页面操作录屏由 `demo/`（高保真可交互原型，与小程序**同源数据/资源**）经 Playwright 真实点击走通三链路生成；真机像素级渲染以微信开发者工具为准。默认 `useMock = true`，**无需到现场、无需联网即可走完全部链路**。

### 链路一：云游集鳞（约 10–15 分钟，不到现场）
1. 首页云阙开场，点「**随我入宫**」直达丹凤门剧场（首屏即可点，无空白等待）；
2. 逐句推进剧情，开启 **AR 复原**看殿宇原貌、点「史料卡」看可溯源出处；
3. 「接过龙鳞」结算 → 「前往下一点位」，依次走完：丹凤门 → 含元殿 → 宣政殿（廊下食）→ 紫宸殿 → 太液池 → 麟德殿 → 玄武门；
4. 玄武门集齐**七片龙鳞**后点「生成祈愿分享卡」，Canvas 生成「长安祈愿卡」，可**保存相册 / 分享好友**。

> **多景点切换**：巡游页卷首的景点分段可在「大明宫 / 大雁塔」间切换（仅上线景点出现）。选「大雁塔」即按 山门 → 翻经院 → 雁塔圣教序碑 → 雁塔题名 → 塔名由来 走完五点位、集五片龙鳞；终章同样可生成祈愿卡。「我的」页龙鳞墙按景点分区呈现，三统计格（龙鳞/集章/文物）可点进详情。

### 链路二：现场 AR 复原
1. 巡游页切「现场」模式，进入「现场 AR」；
2. 真机通过 **marker 识别图 + VKSession** 在遗址叠加殿宇；不支持时以 **LBS / 罗盘方位**进入触发半径自动叠加复原图；
3. 机型不支持 / 拒绝授权 / 不在现场，自动降级为复原图浏览，不黑屏。

### 链路三：商城意向闭环
1. 「云阙商城」浏览 42 款商品，详情页可 **AR 预览**；
2. 「加入购物车」后结算，或直接「预售登记」；
3. 意向单填写称呼、手机号（前端 + 云函数双重校验），提交后生成意向记录；
4. 云端模式由 `cloudfunctions/intention` 真实**提交 / 查询**；未配置云环境时自动**降级本地登记**，链路不断。

> 切到云端：填 `miniprogram/config/index.ts` 的 `cloudEnvId`、部署 `intention` 云函数，步骤见 `docs/cloud-switch.md`。
