# 长安云阙 · AR文旅助手

跟着赤金走龙「云阙」，在盛唐宫阙与今日遗址之间，把长安走一遍、把典故听一遍、把「长安」带回家。

微信小程序：**景点数字馆 ＋ 云阙 AR 巡游 ＋ 云阙商城**。首个景点为**大明宫国家遗址公园**，后续以模板扩展到其他文旅景点。

## 功能特性
- **景点介绍（数字馆）**：历史时间线、主要看点、到访信息，可复用模板。
- **云阙 AR 巡游**：七点位互动小剧场——丹凤门、含元殿、宣政殿（廊下食）、紫宸殿、太液池、麟德殿、玄武门；云游/现场双模式，集七片龙鳞、可溯源史料卡。
- **云阙商城**：典藏复刻、潮玩盲盒、城市限定、唐妆首饰、数字AR、体验预约；支持 AR 预览与预售意向登记。

## 技术栈
微信小程序原生 ＋ TypeScript ＋ XRFrame（3D/AR）＋ VisionKit/VKSession ＋ 微信云开发。

## 目录
```
miniprogram/      小程序源码（pages 主包、package-tour/spot/mall 分包、data 数据、components 组件、store 状态、utils 能力）
cloudfunctions/   云函数（intention 意向登记）
docs/             PRD、技术架构、AR 契约
content/          内容与脚本资料
scripts/          辅助脚本
```

## 快速开始
1. 用「微信开发者工具」导入仓库根目录。
2. 填入你的小程序 AppId（当前为测试号 `touristappid`）。
3. 安装依赖并「构建 npm」（XRFrame）。
4. 开通云开发后，将环境 ID 填入 `miniprogram/config/index.ts`。
5. 首页点「随我入宫」体验丹凤门剧场；真机上可体验现场 AR。
