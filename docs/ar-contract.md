# AR 技术契约

## 1. 能力与版本
- VKSession（`wx.createVKSession`），页面内单例、与页面生命周期绑定、页面间互斥。
- v1：单平面检测；v2：真实物理距离定位、平面识别、点击放置；机型有限（iOS 基础库 2.22、安卓 2.25 起），安卓 v2 不支持竖直平面、需平移初始化。
- Marker：2D 图片识别（可多 marker，需基础库较新版本）；3D 物体识别（OSD）。
- XRFrame：`xr-scene` / `xr-ar-tracker`，支持 marker 与 VIO，加载 glb/glTF。

## 2. 现场定位策略（按优先级）
1. **识别图 marker（主）**：点位解说牌/通关文牒图案，稳定可控。
2. **VIO 平面（辅）**：在有纹理的平整地面放置殿宇模型。
3. **LBS＋罗盘方位叠加（兜底）**：GPS 判定点位、陀螺仪决定朝向，相机画面上固定方位叠加，不依赖平面检测。

> 结论：不在户外开阔、低纹理夯土场地上依赖裸平面检测。

## 3. 点位与触发
- 每点位 `geo: { latitude, longitude, radius }`，现场进入半径触发。
- 现场坐标为近似值，M2 需实测校准。
- 云游模式不使用 geo，按路线顺序解锁。

## 4. 资源规范
- 3D：`.glb`（单贴图、Draco/网格压缩），命名 `models/<sceneId>.glb`。
- 识别图：`markers/<sceneId>.png`，高对比、亚光、避免反光与重复纹理。
- 配音：`.m4a/.mp3`，单声道、合适码率，按对话节点命名。
- 资源统一经 CDN（`config.cdnBase`），并在小程序后台配置合法域名。

## 5. 降级矩阵
| 条件 | 行为 |
|---|---|
| 支持 v2＋识别到 marker | 完整 AR 殿宇贴合 |
| 仅支持 v1/平面可用 | 平面放置模型 |
| 平面不可用、定位可用 | 方位叠加＋语音讲解 |
| 无相机/定位权限 | 引导授权；仍可云游模式 |
| 远程/云游 | 纯 XRFrame/沉浸式场景，不请求实地 |

## 6. 生命周期与性能
- 进入剧场/AR 页创建会话，离开立即销毁（VKSession、相机、音频）。
- 模型与贴图按需加载、复用缓存；监测内存与帧率，超限降级精度。
